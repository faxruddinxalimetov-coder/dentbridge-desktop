# DentBridge — Windows dasturi

DentBridge Online platformasining Windows uchun dasturi (exocad bilan birga ishlash).

**Yuklab olish:** [Releases](../../releases/latest) bo'limidan `DentBridge-Setup.exe` faylini yuklab oling va ishga tushiring.

- Windows 10 / 11, 64-bit
- O'rnatuvchi hozircha raqamli imzosiz: Windows SmartScreen ogohlantirsa — «Подробнее / More info» → «Выполнить в любом случае / Run anyway».

Bu repozitoriyda faqat o'rnatuvchi fayllar joylashadi.
